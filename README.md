# Math - 산수 연습 앱

덧셈, 뺄셈, 곱셈, 나눗셈 문제를 풀며 스테이지를 클리어하는 산수 연습 앱입니다. iOS와 Android를 모두 지원합니다.

## 프로젝트 구조 (KMP Monorepo)

**Kotlin Multiplatform (KMP) + Compose Multiplatform** 기반으로, UI 로직이 `android/shared/` 에서 iOS/Android 공유됩니다.

```
math-app/
├── android/
│   ├── app/                        # Android 앱 진입점
│   └── shared/
│       └── src/
│           ├── commonMain/         # 공유 UI 및 게임 로직
│           ├── androidMain/        # Android 플랫폼 구현
│           └── iosMain/            # iOS 플랫폼 구현
├── ios/
│   ├── Math.xcodeproj/
│   └── Math/                       # iOS 앱 (shared 프레임워크 사용)
└── README.md
```

## 주요 기능

### 게임 구조
- **4가지 연산:** 덧셈 / 뺄셈 / 곱셈 / 나눗셈
- **스테이지 구성:** 연산당 10단계 × 4연산 = **총 40 스테이지**
- 스테이지 1은 기본 해금, 이전 스테이지 완료 시 다음 스테이지 해금
- 스테이지별 난이도에 따라 문제 범위 자동 조정

### 3-스타 평가 시스템
스테이지 완료 시 정답 수와 평균 풀이 시간을 기준으로 평가:
| 등급 | 조건 |
|------|------|
| ⭐⭐⭐ | 10/10 정답 + 평균 6초 이하 |
| ⭐⭐ | 8개 이상 정답 |
| ⭐ | 1개 이상 정답 (완료) |

- 최고 기록만 저장 (재도전 시 점수 하락 없음)

### 포인트 보상 시스템
스테이지 난이도 및 획득 별에 따라 포인트 차등 지급:
| 난이도 | 1⭐ | 2⭐ | 3⭐ |
|--------|-----|-----|-----|
| Easy (1~3단계) | 100 | 110 | 120 |
| Normal (4~6단계) | 150 | 165 | 180 |
| Hard (7~10단계) | 200 | 220 | 240 |

### 하트 (에너지) 시스템
- 최대 하트 15개, 스테이지 시작 시 1개 소모
- 5분마다 하트 1개 자동 충전
- 앱 재시작 시 오프라인 시간만큼 하트 자동 회복
- 메인 화면에서 다음 충전까지 남은 시간 표시

### 화면 구성
```
메인 화면 (하트/포인트 표시)
  ├─ 이어하기 → 게임 화면
  ├─ 새로 시작 → 카테고리 선택
  │   └─ 연산 선택 → 스테이지 맵
  │       └─ 스테이지 선택 → 게임 화면
  │           └─ 완료 → 결과 화면
  │               ├─ 다시 도전 → 게임 화면
  │               ├─ 다음 스테이지 → 게임 화면
  │               └─ 스테이지 맵으로
  └─ 설정 (테마, 언어, 기록 초기화)
```

### 기타 기능
- 3-2-1-GO! 카운트다운 후 게임 시작
- 커스텀 숫자 키패드 + 하드웨어 키보드 지원 (Android/iPad)
- 3-star 달성 시 꽃가루(컨페티) 애니메이션
- 다크/라이트 모드 지원
- **5개 언어 지원:** 한국어, English, 中文(繁體), 中文(简体), 日本語
- 가로/세로 화면 반응형 레이아웃

## 실행 방법

### Android

Android Studio에서 `android/` 폴더를 열거나, 커맨드라인으로 실행:

```bash
cd android
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

**요구사항**
- Android Studio 또는 JDK 17+
- Android SDK 34 (minSdk 26)

### iOS

1. Xcode에서 `ios/Math.xcodeproj` 열기
2. 시뮬레이터 또는 실제 기기 선택
3. ⌘R로 빌드 및 실행

**요구사항**
- Xcode 15.0 이상
- iOS 17.0 이상
