# 브랜드 전략

이 문서는 `Math` 프로토타입을 실제 스토어 출시용 브랜드 `셈토끼`로 전환하기 위한 기준 문서다.

- 문서 상태: 실행 기준안
- 기준 앱: 어린이 사칙연산 학습 앱, Kotlin Multiplatform/Compose Multiplatform
- 정책 확인일: 2026-04-25
- 브랜드 확정일: 2026-04-25
- 관련 실행 문서: [store-release-roadmap.md](./store-release-roadmap.md), [store-listing-metadata.md](./store-listing-metadata.md), [store-creative-assets.md](./store-creative-assets.md)

## 1. 검토 결과

기존 별/셈/모험 조합의 후보는 별 보상, 스테이지, 보물, 모험 구조를 잘 담는 안정적인 이름이었다. 다만 실제 브랜드명으로는 다소 설명형이고 길며, 아이가 기억하고 말하기에는 `셈토끼`가 더 강하다.

최종 브랜드는 `셈토끼`로 간다. 단, 현재 앱에는 곰돌이, 토끼, 여우, 부엉이 등 여러 선택 캐릭터가 있으므로 `셈토끼 = 사용자가 고르는 유일한 캐릭터`로 정의하지 않는다.

핵심 정의:

- `셈토끼`는 앱의 대표 마스코트이자 안내자다.
- 사용자가 고르는 곰돌이/토끼/여우/부엉이는 `모험 친구들`이다.
- 셈토끼는 온보딩, 스토어 소재, 아이콘, 안내 문구에서 앱의 얼굴 역할을 한다.
- 아이는 셈토끼의 안내를 받으며 원하는 모험 친구를 골라 학습한다.

이렇게 정의하면 `셈토끼`라는 짧고 강한 브랜드를 쓰면서도 여러 동물 캐릭터 선택 구조와 충돌하지 않는다.

## 2. 브랜드 결론

- 브랜드명: `셈토끼`
- 앱 표시 이름: `셈토끼`
- App Store 이름: `셈토끼`
- Google Play 이름: `셈토끼: 어린이 연산 놀이`
- 한 줄 설명: `셈토끼와 떠나는 첫 연산 모험`
- 핵심 포지셔닝: `초등 저학년이 모험 친구와 놀이처럼 즐기고, 부모는 안심할 수 있는 사칙연산 학습 앱`
- 1차 출시 분류: `교육 앱`
- 1차 출시 수익화: `무료, 광고 없음, 인앱 결제 없음`

## 3. 왜 셈토끼인가

`셈토끼`는 `셈`과 `토끼`가 바로 붙어 있어 앱의 목적과 대표 캐릭터를 즉시 전달한다.

장점:

- 짧고 기억하기 쉽다.
- 아이가 소리 내어 말하기 쉽다.
- 아이콘과 마스코트 확장이 쉽다.
- 부모에게도 수학/연산 앱이라는 힌트를 준다.
- 스토어 이름에 `어린이 연산 놀이`를 붙이면 검색성과 설명력을 보완할 수 있다.

리스크와 해결:

| 리스크 | 해결 |
|---|---|
| 여러 동물 캐릭터와 충돌할 수 있음 | 셈토끼를 `안내자`, 선택 캐릭터를 `모험 친구들`로 정의 |
| 별/보물/스테이지 세계관이 이름에서 빠짐 | 스토어 부제와 앱 내부 용어에서 `연산 모험`, `별`, `보물`을 유지 |
| 토끼 중심 브랜드가 너무 강해질 수 있음 | 온보딩에서 `셈토끼와 모험 친구들` 구조를 명확히 보여줌 |

## 4. 브랜드 약속

`셈토끼`는 아이에게는 매일 조금씩 별을 모으는 연산 모험이고, 부모에게는 광고와 개인정보 수집 없이 로컬에서 학습 기록을 확인할 수 있는 안전한 첫 사칙연산 앱이다.

스토어와 앱 내부에서 반드시 지킬 약속:

- 아이가 바로 학습을 시작할 수 있어야 한다.
- 부모가 걱정할 만한 광고, 외부 링크, 채팅, 사용자 생성 콘텐츠를 넣지 않는다.
- 학습 기록은 기기 안에만 저장한다.
- 성취감은 별, 별코인, 보물, 배지로 표현하되 실제 돈과 혼동되지 않게 한다.
- 연산 실력에 대해 과장된 성과 표현을 쓰지 않는다.

## 5. 이름 사용 규칙

| 위치 | 문구 |
|---|---|
| 앱 아이콘 텍스트 | 사용하지 않음 |
| iOS/Android 앱 표시 이름 | `셈토끼` |
| App Store 이름 | `셈토끼` |
| App Store 부제 | `모험 친구와 배우는 사칙연산` |
| Google Play 이름 | `셈토끼: 어린이 연산 놀이` |
| Google Play 짧은 설명 | `셈토끼와 모험 친구들이 스테이지를 탐험하며 사칙연산을 익혀요` |
| 대외 첫 문장 | `셈토끼는 모험 친구들과 함께 사칙연산을 익히는 어린이 연산 모험 앱입니다.` |

금지:

- 앱 이름에 `무료`, `1위`, `최고`, `인기`, `다운로드`, `할인` 같은 성과/프로모션 표현을 넣지 않는다.
- 아이콘에 글자를 넣지 않는다.
- `초등 수학 완전 정복`, `성적 향상 보장`처럼 검증 불가능한 표현을 쓰지 않는다.

## 6. 캐릭터 체계

### 대표 마스코트

- 이름: `셈토끼`
- 역할: 브랜드 대표 얼굴, 앱 안내자, 스토어 소재의 중심
- 성격 키워드: `밝음`, `재빠름`, `친절함`, `응원형 안내자`
- 앱 내 위치:
  - 온보딩 첫 화면
  - 캐릭터 선택 화면의 안내 말풍선
  - 스토어 아이콘
  - 스토어 스크린샷 1번
  - 학습 성공/퀘스트 안내 문구

### 모험 친구들

- 대상: 곰돌이, 토끼, 여우, 부엉이
- 역할: 사용자가 선택하는 학습 동료
- 화면 표현: `오늘 함께할 모험 친구를 골라요`
- 주의: 선택 캐릭터 중 토끼가 있더라도 브랜드 마스코트 `셈토끼`와 혼동되지 않게 이름/디자인을 구분한다.

권장 구분:

- 셈토끼: 작은 선생님/안내자 느낌, 별 배지 또는 스카프 보유
- 선택 토끼 캐릭터: 사용자의 친구 캐릭터, 더 단순하고 커스터마이즈 가능

## 7. 브랜드 톤

- 핵심 감정: `안심`, `성취`, `밝음`, `모험`, `친근함`
- 아이에게 주는 인상: `셈토끼가 길을 알려주고, 내가 고른 친구와 같이 배우는 느낌`
- 부모에게 주는 인상: `가볍지 않지만 부담스럽지 않은 교육 앱`
- 문장 톤: 짧고 다정하게, 지시보다 초대에 가깝게

피해야 할 방향:

- 지나치게 유아용처럼 보이는 베이비 톤
- 너무 교재처럼 보이는 딱딱한 학습 톤
- 어두운 계산기/시험지 느낌
- 경쟁, 압박, 순위 중심의 문구

## 8. 앱 아이콘 방향

### 메인 콘셉트

- 구성: `셈토끼 얼굴 + 별 배지 + 작은 연산 기호 1개`
- 인상: `밝고 따뜻하고, 한눈에 어린이 연산 앱으로 읽히는 아이콘`
- 형태: 앱 아이콘 안에서 상반신보다 `얼굴 중심 클로즈업`

### 추천 구도

- 중앙에 밝은 아이보리 톤 셈토끼 얼굴
- 오른쪽 위 또는 왼쪽 위에 금색 별 배지
- 별 안이나 옆에 작은 `+` 기호 배치
- 배경은 하늘색 또는 민트-블루 계열
- 스카프나 작은 별 배지로 `안내자` 정체성 부여

### 추천 팔레트

- Sky Blue: `#58C7F3`
- Mint Blue: `#8FE3DA`
- Warm Ivory: `#FFF7E8`
- Star Yellow: `#FFD34D`
- Coral Pink: `#FF8E7A`
- Deep Navy: `#35506B`

### 반드시 지킬 것

- 텍스트 넣지 않기
- 숫자나 기호는 보조 요소로만 사용하기
- 배경을 검정이나 회색 계열로 두지 않기
- 캐릭터는 셈토끼 한 명만 사용하기
- 작은 화면에서도 `셈토끼`, `별`, `밝은 배경`이 먼저 보이게 하기

## 9. 아이콘 제작 브리프

디자이너/이미지 생성용 마스터 브리프:

> 초등 저학년 대상의 어린이 연산 학습 앱 아이콘. 둥글고 사랑스러운 흰 토끼 얼굴이 화면 중앙에 크게 보인다. 이 토끼는 앱의 안내자 `셈토끼`이며, 밝게 웃고 있고 작은 스카프나 별 배지로 친절한 모험 안내자 느낌을 준다. 한쪽 옆에는 금색 별 배지가 있고 작은 더하기 기호가 함께 보인다. 배경은 밝은 하늘색과 민트색이 섞인 부드러운 분위기다. 전체 분위기는 따뜻하고 교육적이며 연산 모험을 떠나는 느낌이다. 텍스트는 넣지 않고, 단순하고 선명하며 작은 앱 아이콘 크기에서도 잘 보이도록 구성한다.

시안:

| 시안 | 이름 | 포인트 | 용도 |
|---|---|---|---|
| A | Semtokki Guide | 셈토끼 얼굴 정면 + 별 배지 | 메인 후보 |
| B | Semtokki Explorer | 셈토끼 + 작은 스카프 | 모험 안내자 강조 |
| C | Semtokki Star | 별이 더 크게 보이고 셈토끼는 단순화 | 작은 화면 식별성 테스트 |

## 11. 구현 우선순위

Claude Code는 아래 순서대로 구현한다.

1. 최종 앱 식별자 확정 전까지 스토어 레코드를 만들지 않는다.
2. `AndroidManifest.xml`, `Info.plist`의 표시 이름을 `셈토끼`로 바꾼다.
3. 앱 아이콘을 셈토끼 기반 아이콘으로 교체한다.
4. 온보딩 첫 문구와 캐릭터 선택 화면을 `셈토끼 + 모험 친구들` 구조로 수정한다.
5. `진행상황`, `보물 상자`, `캐릭터 꾸미기`, `상점`, `코인`, `포인트` 용어를 일괄 정리한다.
6. 개인정보/어린이 정책 문서의 금지 항목을 깨는 SDK를 추가하지 않는다.

## 12. 완료 기준

- iOS 홈 화면 앱 이름이 `셈토끼`로 보인다.
- Android 런처 앱 이름이 `셈토끼`로 보인다.
- 앱 아이콘에 텍스트가 없다.
- 첫 화면에서 `Math`라는 이름이 노출되지 않는다.
- 온보딩에서 셈토끼가 안내자이고, 사용자는 모험 친구를 고른다는 구조가 보인다.
- 스토어 메타 문구는 [store-listing-metadata.md](./store-listing-metadata.md)의 최종 문구와 일치한다.
- 광고, 분석, 결제, 소셜, 외부 링크 SDK가 추가되지 않았다.
