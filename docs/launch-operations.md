# 런칭 운영 계획

이 문서는 스토어 제출 이후 운영 기준이다. 1차 출시는 작게 열고, 피드백을 보고 안정적으로 확장한다.

## 출시 원칙

- 기능보다 신뢰를 우선한다.
- 어린이 대상 앱이므로 광고, 결제, 외부 링크, 데이터 수집은 출시 후에도 기본적으로 넣지 않는다.
- 리뷰 요청이나 마케팅 문구는 과장하지 않는다.
- 문제 난이도와 사용성 피드백을 가장 먼저 본다.

## 출시 전 운영 준비

필수:

- [ ] 지원 이메일 준비
- [ ] 개인정보 처리방침 URL 공개
- [ ] 지원 URL 공개
- [ ] App Store Connect 권한 확인
- [ ] Play Console 권한 확인
- [ ] 스토어 스크린샷과 설명 최종 검수
- [ ] 앱 심사 노트 준비
- [ ] 베타 피드백 요약 준비

지원 페이지 최소 내용:

- 앱 소개
- 문의 이메일
- 개인정보 처리방침 링크
- 데이터 삭제 안내: 앱 설정의 기록 초기화 또는 앱 삭제 (게스트) / 설정 화면 계정 삭제 버튼 (계정 연동 시 → 3영업일 이내 삭제)
- 광고/결제 없음 안내, 계정은 선택적 연동 가능 안내

## 출시 방식

### App Store

권장:

- 첫 제출은 `Manual Release` 또는 승인 후 직접 출시
- 심사 승인 후 내부 기기에서 최종 확인
- 문제 없으면 출시

업데이트:

- 버그 수정은 빠르게 제출
- 기능 변경은 App Review Notes에 구체적으로 적는다.
- 어린이/개인정보 관련 변경은 개인정보 처리방침과 App Privacy를 먼저 업데이트한다.

### Google Play

권장:

- Internal testing
- Closed testing
- Production staged rollout 10%
- 24-48시간 crash/feedback 확인
- 50%
- 100%

개인 개발자 계정이 신규 조건에 걸리면 production 전에 closed testing 요구사항을 먼저 충족한다.

## 리뷰와 문의 대응

지원 응답 원칙:

- 아이의 개인정보를 요청하지 않는다.
- 문제 재현에 필요한 경우 기기 모델, OS 버전, 앱 버전만 요청한다.
- 스크린샷을 요청할 때 아이 이름이나 개인정보가 나오지 않게 안내한다.
- 게스트 모드 사용자: 서버에 데이터가 없으므로 앱 삭제/기기 변경 후 복구 불가능함을 안내한다.
- 계정 연동 사용자: 앱 재설치 후 동일 계정으로 로그인 → 설정 화면 동기화 버튼으로 복구 가능함을 안내한다.

계정/데이터 관련 문의 대응:

| 유형 | 대응 |
|---|---|
| 학습 데이터 복구 요청 (게스트) | 계정 연동 없이는 복구 불가. 이후 계정 연동 권장 안내 |
| 학습 데이터 복구 요청 (계정 연동) | 동일 계정 로그인 후 설정 화면 "데이터 동기화" 안내 |
| 계정 삭제/데이터 삭제 요청 | 앱 설정 → 계정 삭제 버튼 안내. 이메일 문의 시 3영업일 이내 처리 |
| 이메일 인증 메일 미수신 | 스팸함 확인, 1-2분 대기 후 재시도 안내 |
| 비밀번호 재설정 | 앱 로그인 화면 "비밀번호를 잊으셨나요?" 버튼 안내 |

리뷰 대응 톤:

- 짧고 친절하게
- 방어적으로 쓰지 않기
- 아이가 쓰는 앱이라는 점을 고려해 쉬운 표현 사용

예시:

```text
소중한 의견 감사합니다. 아이가 더 편하게 연산을 연습할 수 있도록 난이도와 화면 흐름을 계속 다듬겠습니다.
```

## 지표 확인

1차 출시에서는 별도 분석 SDK를 넣지 않는다. 아래 스토어 기본 지표만 확인한다.

- App Store Connect: 다운로드, 충돌, 리뷰, 제품 페이지 성과
- Play Console: Android Vitals, 설치, 제거, 리뷰, 사전 출시 보고서
- 지원 이메일: 문의 유형, 반복 이슈

추후 분석 SDK를 넣고 싶다면 [privacy-and-kids-compliance.md](./privacy-and-kids-compliance.md)를 다시 작성하고 Kids/Families 정책을 재검토한다.

## 첫 2주 운영 체크

매일 확인:

- crash/ANR
- 설치 실패
- 리뷰와 별점
- 지원 이메일
- 특정 기기 레이아웃 문제

3일차:

- 치명 이슈가 없으면 Google Play rollout 확대
- 반복 문의가 있으면 지원 페이지 FAQ 추가

7일차:

- 첫 업데이트 후보 정리
- 난이도/온보딩/문구 피드백 반영 여부 결정

14일차:

- 1.0.1 버그 수정 릴리스 여부 결정
- 스토어 스크린샷 전환 개선 여부 검토

## 업데이트 우선순위

1. Crash, 진행 불가, 저장 오류
2. 어린이/개인정보 정책 리스크
3. 작은 화면 레이아웃 깨짐
4. 난이도 조정
5. 스토어 문구와 실제 기능 불일치
6. 신규 기능

## 기능 추가 전 체크

아래 기능은 추가 전에 정책 검토가 필요하다.

- 광고
- 인앱 결제
- 푸시 알림
- 소셜 로그인 추가 (Apple 로그인 등)
- 랭킹
- 친구 기능
- 채팅
- 학부모 이메일 리포트
- 외부 링크
- 분석/크래시 SDK

## 완료 기준

- 출시 후 48시간 동안 치명 crash가 없다.
- 스토어 설명과 실제 기능이 일치한다.
- 개인정보/어린이 정책 문의가 없다.
- 지원 이메일이 정상 수신된다.
- 다음 업데이트 후보가 정리되어 있다.
